# coyyngx78's NixOS configuration
This is my NixOS configuration that I use on my Framework 16 (7040 series) laptop.
## Installing
In order to use, first git clone this repository to wherever you want. Then, tweak some settings such as the hostname and the users, and remove my nixos-hardware stuff. If it is a fresh install, make sure you have git. Finally, rebuild, using --flake.
